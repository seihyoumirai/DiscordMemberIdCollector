# Auto Discord Server Member Id Collecter

自動でサーバーに参加しているユーザーのIDを収集します。

---

## 使用方法

1. メンバー表示されるサイドバーを開く
2. 開発者ツールにコードを貼って有効にする
3. `startMemberId()`を実行
4. 自動で止まるか`stopMemberId()`を実行すると、IDがまとめられたファイルがダウンロード

---

## 注意

Discordの規約に違反する可能性があります。

また、クライアント側だけで完結するので、トークン漏洩の心配はありません。

---

## 利用にあたって
1. 自作発言をしないこと
2. 二次配布をしないこと
3. 改造不可
4. 悪用厳禁
